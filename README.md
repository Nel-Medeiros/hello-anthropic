# Hello Anthropic

A small integration test project using the [Anthropic API](https://docs.anthropic.com) with Python.

## Overview

This project demonstrates how to interact with Anthropic's Claude models via the official Python SDK.

## Requirements

- Python 3.8+
- `anthropic` Python SDK

## Setup

```bash
pip install anthropic
```

Set your API key:

```bash
export ANTHROPIC_API_KEY=your_api_key_here
```

## Usage

```bash
python main.py
```
